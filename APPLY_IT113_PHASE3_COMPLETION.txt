INSTALLATION
------------
1. Your project must already contain Phase 1 + original wolf premium UI +
   Phase 2 + Phase 3 files. Do NOT apply this patch to the old original zip.
2. Back up your current TankWeb-v3 folder (you already made a backup earlier).
3. Extract this ZIP, open the TankWeb-v3/ folder inside it, and merge its
   contents into YOUR TankWeb-v3/ folder, preserving subdirectories.
4. Replace only files with matching names. Do not delete other files.
5. Local: start with 'Start FortressAuth.bat'.
   Public research: http://127.0.0.1:8082/assessment/
   Protected operations: /app/ (existing admin authentication still required).
6. Use Ctrl+Shift+R after updating the local web application.
7. If deploying, commit the changed source files and deploy the PHP backend
   and Vercel frontend using the existing deployment pipelines.
   scripts/build-vercel.mjs copies the new versioned React bundle to vercel-dist.
