FORTRESSAUTH IT113 — WOLF LOGO RESTORE + PREMIUM ASSESSMENT UI
=================================================================
This is a design-only update for the Phase 1 login-free assessment workspace.
No ML models, backend services, authentication rules, reports or private data
were changed.

HOW TO APPLY
1. Keep your backed-up TankWeb-v3 folder and close the running server.
2. Open this ZIP. You will see one top-level directory named TankWeb-v3.
3. Copy/merge its CONTENTS onto your current TankWeb-v3 project folder.
   When prompted, replace ONLY the three assessment UI files listed below.
   The two original logo images are bundled to restore any missing assets.
4. Start the project as before with "Start FortressAuth.bat".
5. Open http://127.0.0.1:8082/assessment/ and hard-refresh (Ctrl+Shift+R).
